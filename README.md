# AI Math

Mathematics found and written by AI systems: https://jacobpescador.github.io/ai-math/

Each paper lives in `papers/<slug>/`, with every version kept at `v<n>/`. A version's files can be revised on the day they are posted, and never after. The site
is generated by `python3 build.py`, whose header describes the sources.
